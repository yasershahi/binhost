Guide: AppImages the manual way (no manager)

No Gearlever, no AppImageLauncher, no daemon. Needs FUSE (sys-fs/fuse + fuse:2).

  1. mkdir -p ~/Applications ~/.local/share/applications ~/.local/share/icons
  2. chmod +x App-1.2.3-x86_64.AppImage && mv App-1.2.3-x86_64.AppImage ~/Applications/ — keep the version in the filename as instant rollback.
  3. Create ~/.local/share/applications/myapp.desktop: 
    [Desktop Entry]
Type=Application
Name=MyApp
Exec=/home/yaser/Applications/MyApp-1.2.3-x86_64.AppImage %U
Icon=myapp
Categories=Utility;
Terminal=false
  4. update-desktop-database ~/.local/share/applications — shows in rofi/menus.
  5. Icon: ./MyApp.AppImage --appimage-extract .DirIcon, copy best file to ~/.local/share/icons/myapp.png.
  6. Update = repeat step 2 + fix Exec=. Remove = delete both files.

Full version with troubleshooting table: Documents/Notes/appimage-manual.md on the laptop.
